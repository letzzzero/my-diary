# My Diary (personal)

Личный мини-сайт: дневник по датам + цели. Простая авторизация только для тебя (логин/пароль в `.env`).

## Запуск локально
1) Установи Node.js (LTS)
2) Установи зависимости:
```bash
npm install
```
3) Создай `.env` по примеру:
```bash
cp .env.example .env
```
4) Запуск:
```bash
npm start
```
Открой: http://localhost:3000

## Важно
- Это "для себя" и без серьёзной защиты.
- `.env` не коммить в GitHub (он в `.gitignore`).
- База SQLite хранится в `data.sqlite` (тоже не коммить).
